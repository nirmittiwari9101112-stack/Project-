# Shilalekh — 100 Inscriptions of the World

Shilalekh is an interactive digital heritage and e-tourism website for exploring 100 historical inscriptions from India and around the world.

## Features

- 100 inscription records
- Search by inscription, location, era, script and description
- India / World filtering
- Indian state and international country labels
- Interactive Leaflet/OpenStreetMap heritage map
- Site details and map-safe modal overlay
- Multilingual translation interface with 27 target languages
- Enhanced browser text-to-speech audio guides
- Virtual-tour discovery links
- Directions and travel-planning links
- Personal heritage trail with browser-local saving
- Printable heritage itinerary
- Bright, responsive, mobile-friendly interface
- No build process required

## GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html` and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Save and open the GitHub Pages URL generated by GitHub.

## Important

The interactive map and online translation services require an internet connection. Audio voices are supplied by the visitor's browser/device, so voice availability varies by device and operating system.

Translations generated by online machine-translation services should be treated as educational aids rather than authoritative epigraphic editions.
